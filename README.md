# HODOR — نظام الحضور والانصراف للمكتبة الحديثة

واجهة عربية RTL متجاوبة تعمل على الهاتف والكمبيوتر. تعتمد على Supabase Auth + PostgreSQL + Realtime.

## محتويات المشروع
- `index.html` الواجهة.
- `style.css` التصميم.
- `app.js` منطق التطبيق.
- `supabase.sql` الجداول، صلاحيات RLS، ودوال تسجيل الحضور والانصراف.

## 1) إنشاء قاعدة البيانات
1. افتح https://supabase.com وأنشئ مشروعاً جديداً.
2. من SQL Editor شغّل كامل محتوى `supabase.sql`.
3. من Project Settings > API انسخ Project URL و anon/public key.
4. افتح `app.js` واستبدل:
   - `https://YOUR-PROJECT.supabase.co`
   - `YOUR-SUPABASE-ANON-KEY`
5. لا تضع `service_role` key في ملفات الموقع أبداً.

## 2) إنشاء حساب المدير
1. من Supabase > Authentication > Users اختر Add user وأنشئ حساباً ببريدك وكلمة مرور.
2. من SQL Editor نفّذ (مع تغيير البريد):
   ```sql
   update public.profiles
   set role='admin', full_name='مدير المكتبة'
   where email='YOUR_ADMIN_EMAIL';
   ```
3. سجّل الدخول من الموقع.

## 3) إضافة الموظفين
1. أنشئ لكل موظف حساباً من Authentication > Users مع البريد وكلمة المرور.
2. سيُنشأ ملف الموظف تلقائياً في `profiles`.
3. افتح إدارة الموظفين داخل HODOR، وأدخل البريد والاسم ومواعيد الدوام لإكمال البيانات.
4. الحسابات الجديدة تبدأ بدور `employee`.

## 4) ضبط موقع المكتبة
1. افتح إعدادات و QR من حساب المدير.
2. أدخل Latitude و Longitude لمقر المكتبة ونطاق السماح بالمتر.
3. يمكن استخراج الإحداثيات من خرائط Google عبر الضغط المطول على موقع المكتبة.
4. اضبط دقائق السماح للتأخير.

## 5) النشر على GitHub Pages
1. افتح المستودع `7oda90/HODOR9`.
2. ارفع `index.html`, `style.css`, `app.js`.
3. من Settings > Pages اختر Deploy from a branch ثم `main` و `/root`.
4. افتح رابط الموقع عبر HTTPS. الكاميرا وGPS يحتاجان HTTPS أو localhost.
5. احتفظ بملف `supabase.sql` لتشغيل قاعدة البيانات.

## طرق التسجيل
- حساب الموظف: تسجيل مباشر من الحساب.
- GPS: يتحقق النظام من المسافة إلى إحداثيات المكتبة.
- QR + GPS: يمسح الموظف رمزاً مؤقتاً من لوحة المدير، ثم يسجل العملية مع التحقق من الموقع.
- QR صالح لدقيقتين ويُستهلك عند أول عملية تسجيل.

## ملاحظات مهمة قبل التشغيل الفعلي
- هذه نسخة تأسيسية جاهزة للربط والنشر بعد إدخال بيانات Supabase وإنشاء الحسابات وضبط الموقع.
- GPS في المتصفح يعتمد على الجهاز والمتصفح ويمكن التحايل عليه بأدوات متخصصة؛ لا تعتبره إثباتاً أمنياً مطلقاً. للمستوى الأعلى، استخدم جهاز كشك ثابت داخل المكتبة أو تحققاً إضافياً.
- تسجيل الدخول يعتمد على Supabase Auth. لا يوجد تسجيل ذاتي من صفحة الموقع.
- يفضّل تفعيل تأكيد البريد وسياسة كلمات مرور قوية من إعدادات Supabase.
- لا تشارك كلمات مرور الموظفين بين بعضهم، ولا تستخدم حساب المدير على أجهزة الموظفين.
- النسخة الحالية تحسب سجل حضور واحداً لكل موظف في اليوم، وتستخدم توقيت `Africa/Cairo`.
- التقارير قابلة للتصدير CSV ويمكن فتحها في Excel.
